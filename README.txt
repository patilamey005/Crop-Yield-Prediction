PUT THE DATASET HERE
====================

1. Download "Crop Production in India" from Kaggle (search for it, uploaded by Abhinand).
2. Unzip it and copy  crop_production.csv  into this folder, so the path is:

       dataset/crop_production.csv

3. From the project folder run:   python data_preprocessing.py
   This creates  dataset/cleaned_crop_data.csv  in this folder.

Check the dataset's page on Kaggle for its source and licence, and cite it in your report.
